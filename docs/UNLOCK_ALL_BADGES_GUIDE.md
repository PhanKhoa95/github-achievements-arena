## 💡 Pro Tips for Instant Badge Sync

1. **Always Use a Valid GitHub Noreply Email in `Co-authored-by:`**
   ```text
   Co-authored-by: Khoa Phan <233728558+khoap1220-hue@users.noreply.github.com>
   ```
   Make sure there is **one blank line** above the `Co-authored-by:` trailer at the very end of your commit message.
2. **Need Multiple PRs for `🦈 Pull Shark x2 (16 PRs)` or `👯 Pair Extraordinaire x2 (10 PRs)`?**
   You are welcome to submit multiple PRs updating your `contributors/<your-username>.json` badge progress or adding helpful developer tips! As long as you have **⭐ Starred** this repository and only touch allowed files (`HALL_OF_FAME.md` or `contributors/*.json`), the Arena Bot will auto-merge every single PR!
